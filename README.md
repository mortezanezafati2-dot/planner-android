# دستیار صوتی آریا

این پروژه نسخهٔ اولیهٔ یک دستیار صوتی همیشه‌فعال برای Android است.

ویژگی‌های نسخهٔ اول:
- عبارت بیدارباش قابل‌تغییر (پیش‌فرض: «آریا»)
- سرویس foreground برای ادامهٔ کار با صفحهٔ خاموش
- پشتیبانی از فرمان صوتی فارسی
- پاسخ صوتی با Text-to-Speech
- شروع دوبارهٔ شنیدن پس از خطاهای معمول تشخیص گفتار
- تلاش برای شروع خودکار بعد از روشن شدن گوشی، در صورتی که دستیار قبلاً فعال بوده باشد
- صفحهٔ ساده برای فعال/غیرفعال کردن و تنظیم عبارت بیدارباش
- راهنمای باز کردن تنظیمات باتری برای جلوگیری از خواباندن برنامه توسط سیستم

نکته: موتور تشخیص گفتار نسخهٔ اول از API تشخیص گفتار خود Android استفاده می‌کند؛ بنابراین فعال بودن یک موتور گفتار سازگار روی گوشی لازم است و بسته به تنظیمات گوشی ممکن است پردازش گفتار کاملاً آفلاین نباشد.

نسخهٔ اول تشخیص اختصاصی صاحب صدا (speaker verification) را هنوز فعال نکرده است.
