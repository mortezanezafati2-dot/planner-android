# حسابداری پرتابل — نسخه اندروید

نسخهٔ اندرویدی نرم‌افزار «حسابداری پرتابل» با Android WebView بسته‌بندی شده است.

## امکانات
- رابط راست‌به‌چپ و سازگار با موبایل
- ثبت و نمایش عکس کالا
- جداکنندهٔ سه‌رقمی برای ورودی‌های عددی
- نگهداری اطلاعات در localStorage دستگاه
- انتخاب عکس کالا از گالری/فایل‌منیجر
- بازیابی بکاپ JSON
- پشتیبان‌گیری با پنجرهٔ ذخیرهٔ بومی اندروید

## ساخت
ساخت APK توسط GitHub Actions انجام می‌شود.
