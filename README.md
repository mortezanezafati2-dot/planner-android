# پلنر من — بولت ژورنال اندروید

اپلیکیشن بومی Android با Kotlin و Jetpack Compose، بر اساس ساختار و امکانات فایل مرجع `planner_034.html`.

## امکانات فعلی
- رابط فارسی راست‌به‌چپ و ظاهر روشن/تیره/پیروی از سیستم
- داشبورد روزانه و ثبت/علامت‌گذاری/حذف کارها
- یادداشت روزانه با ذخیرهٔ خودکار
- فهرست عادت‌ها و ثبت انجام روزانه
- ثبت رویدادها و تاریخ آن‌ها
- مرور و بازتاب روزانه
- پشتیبان‌گیری و بازیابی JSON از طریق انتخابگر فایل اندروید
- ضبط یادداشت صوتی با درخواست مجوز میکروفون

## ساخت APK
در GitHub Actions گردش‌کار **Build Bullet Journal APK** را اجرا کن. فایل APK در بخش Artifacts با نام `bullet-journal-apk` قرار می‌گیرد.

شناسهٔ برنامه: `ir.bulletjournal.app`
