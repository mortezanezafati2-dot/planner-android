# TradingBoard Native Windows

بازنویسی native ویندوزی بر پایه TradingBoard_v12.html. این نسخه با Python/Tkinter و SQLite ساخته می‌شود و در Windows یک EXE و Installer واقعی تولید می‌کند؛ مرورگر یا WebView در runtime استفاده نمی‌شود.

قابلیت‌های اصلی: داشبورد، پروژه‌ها، ثبت/ویرایش معاملات، تحلیل آماری، ایده‌ها، آزمایشگاه، تقویم، گزارش، تنظیمات، Backup/Restore و CSV.

منبع اصلی در فایل ارسالی گفتگو: TradingBoard_v12.html.
